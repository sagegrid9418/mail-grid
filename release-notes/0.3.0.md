# Mail Grid 0.3.0 beta

- Required first-launch setup for interface language, System/Light/Dark appearance, Manual/Automatic update downloads, and independent automatic update checks. Existing profiles migrate without resetting accounts or preferences.
- Offline interface language selector using pinned CLDR 48 (766 locales, 323 language identities), with right-to-left layouts and localized formatting. English is complete; 21 languages have translated core controls and count/update/copy messages; 8 include translated setup explanations. Remaining interface text uses English fallback. Full translations of every locale are not included in this beta.
- Original email content is never translated. HTML preview retains message-local styles, blocks scripts and remote resources, and renders supported MIME character sets. Message subjects and searches correctly decode encoded Unicode headers.
- Free Ed25519 release verification and checksums, embedded public trust keys, and clearer update states. Paid platform certificates and notarization are optional.
- A universal macOS DMG with native Intel and Apple Silicon components. Approved Mac updates use a detached helper, staged replacement, startup confirmation and previous-app rollback.
- Update-compatible Windows NSIS installation and Linux DEB/AppImage target support. Users choose when downloads happen and explicitly approve installation; Later and ordinary quit do not install.
- Independent OS/package releases, per-target versions, same-version additions for other platforms, immutable published files, withdrawal and compatible fallback, and a version-2 feed while preserving legacy endpoints.

Existing keyless installations need one manual installation of 0.3.0 before receiving verified updates. macOS permission or security prompts may still appear.

Validation: isolated engine/protocol/UI/browser workflows and native Mac helper replacement/rollback with disposable universal mock apps. Native clean-install/update tests on Windows, Linux and Apple Silicon, and real installed-app permission/startup behavior after Mac replacement, remain unverified on this build computer. Artifact checks and mock rehearsals do not replace those tests.
