# Mail Grid 0.3.2

- Update downloads retain progress after a network interruption or app restart. Downloads already requested resume even with Manual downloads and automatic checks disabled.
- Pause, Resume and Cancel download are available in Software updates. Pause survives restarts; Cancel discards the transfer and prevents automatic restarting of that artifact until requested again.
- Signed metadata is refreshed before resuming. Complete downloads and staged installers are verified with SHA-256 and SHA-512. Withdrawn or changed artifacts cannot install.
- Download status shows saved progress, retry timing and final verification. Freeing disk space allows a paused transfer to continue. Installation still requires Update now; Later, closing the panel and ordinary quitting never install updates.
- Interface translations are bundled locally. The selector offers complete catalogs only, keeps English first and preserves supported regional formatting. Email content remains unchanged. See LANGUAGES.md for the exact scope and translation review limitations.

Rollout: install 0.3.2 to receive resume support. An older app downloading this first upgrade still uses its existing downloader. OS credential storage and its permission prompts are unchanged. Mail, accounts and owner data are preserved.

These beta packages use free release-signature verification. Paid publisher certificates/notarization remain optional. Native Windows/Linux/Apple Silicon installation and update checks require those systems and are not implied by cross-building their artifacts.
